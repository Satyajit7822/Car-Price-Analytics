# Car Price Analytics

## Dashboard Preview

![Car Price Dashboard](Image/dashboard.png)

## Project Overview

This project analyzes a dataset of 205 vehicles across 22 brands using Excel dashboards and visual analytics techniques.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization

## Key Findings
- Sedans and hatchbacks account for 77% of the market.
- Front-wheel-drive vehicles dominate the dataset.
- 4-cylinder engines represent the majority of vehicles.
- Premium vehicles are low in volume but high in value.
- Body style, drivetrain, and cylinder count are strong price indicators.
